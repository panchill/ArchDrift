# ArchDrift frontend

React + TypeScript + Vite + Cytoscape.js. Локальный прототип работает без бэкенда.

## Запуск

Нужен Node.js 22.12+ в ветке 22 LTS (или поддерживаемая версия 24+).

```bash
cd frontend
nvm use # если установлен nvm; иначе выберите Node.js 22 самостоятельно
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://127.0.0.1:5173).

```bash
npm test        # unit, contract и integration тесты
npm run build  # проверка TypeScript и production-сборка
```

## Данные и интерфейс

- `public/mocks/architecture.json` — ответ `GET /api/v1/architecture`: CALM 1.2 внутри `model`, версия и время обновления.
- `public/mocks/analysis.json` — ответ `GET /api/v1/analysis`: нормализованный наблюдаемый граф, метрики, нарушения и диагностика.
- Один снимок магазина: 5 сервисов, 8 HTTP endpoints, 2 воркера, 3 базы PostgreSQL, 3 Kafka-топика; 17 детальных связей.
- Два `unexpected`: payments читает чужую orders_db; orders публикует в отсутствующий в CALM orders.debug.
- Один `indeterminate`: у вызова orders → payments неизвестен endpoint назначения, а декларация точная.
- Endpoint отмены заказа объявлен, но не наблюдался. Неизвестный Kafka-топик помечен `known=false`.
- Синтетические trace/span IDs показываются как примеры; реальных трейсов и Jaeger в этом прототипе нет.

Переключатель показывает обзор сервисов или endpoints и воркеры внутри сервисов. Поиск оставляет найденные узлы и их непосредственные связи. Фильтр статуса применяется до группировки. Выбор доступен и на canvas, и в раскрывающемся списке с клавиатуры. В боковой панели — подробности связи/узла и переходы к нарушениям.

В сервисном обзоре группируем по source, target, type, dbOperation: счётчики складываются, длительность усредняется с весами по числу операций. Смешанные статусы сохраняются в деталях; цвет определяется приоритетом unexpected → indeterminate → declared. Это правило отображения, а не повторная проверка CALM.

Мок загружается обычным `fetch`, обновление — кнопкой. Временной интервал фиксированный, фоновый polling не имитируется. `src/api.ts` — место для последующего подключения реальных `/api/v1/architecture` и `/api/v1/analysis?from=…&to=…`. Проверка совпадения версий защищает от смешивания двух моделей.

## Проверки

- Unit: группировка, средневзвешенные метрики, приоритет статусов, фильтрация, поиск, parentId и стабильные ID.
- Contract: структура ответов по OpenAPI, CALM по официальным локальным схемам, ссылки узлов/интерфейсов, владение воркерами и согласованность нарушений.
- Integration: загрузка HTTP-моков, React-состояния, фильтры, выбор и события реального Cytoscape, ошибки/повторная загрузка, очистка ресурсов.

В jsdom Cytoscape работает с настоящим графом, но без canvas-рендерера. Эти тесты не заменяют визуальную проверку в браузере.
