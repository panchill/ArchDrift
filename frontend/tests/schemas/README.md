# CALM 1.2 schemas

Unmodified official schemas from https://calm.finos.org/release/1.2/meta/:
`core.json`, `interface.json`, `control.json`, `flow.json` (FINOS CALM).

Used offline by the fixture tests. `core.json` validates CALM vocabulary;
ArchDrift-specific bindings and cross references are checked separately.
Tests do not fetch remote schemas or run a backend.
